python-wheels

Prebuilt Python wheels for platforms upstream projects don't ship — currently Windows on ARM64. Every wheel here is built in CI from a pinned, verified upstream commit and signed with Sigstore build attestations.

Use it

pip install --extra-index-url https://python-wheels.github.io/simple/ <package>

Packages

→ dbt-oss — standard OSS distribution, win_arm64
→ dbt-core — legacy name, being phased out upstream, win_arm64

Verify a wheel yourself

gh attestation verify <wheel> --repo patrickryankenneth/python-wheels-builds

Each release records the exact upstream commit it was built from, so you can independently confirm it against the real tag with git ls-remote — see python-wheels-builds for the build workflow.
